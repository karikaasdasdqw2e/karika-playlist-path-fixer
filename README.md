# KARIKA Playlist Path Fixer

أداة مجانية لتغيير بداية مسارات الأغاني في مجموعة ملفات M3U وM3U8 دفعة واحدة، بواجهة عربية.

## الاستخدام

1. افتح الأداة، أو نزّل `index.html` وافتحه في Chrome أو Edge.
2. اكتب المسار القديم والمسار الجديد لحد مجلد `Contents`.
3. اسحب ملفات البلاي ليست أو اخترها من جهازك.
4. راجع المعاينة واضغط **تنزيل الملفات المعدّلة ZIP**.
5. فك الضغط واستورد النسخ الجديدة في برنامج الـ DJ.

البرنامج يغيّر بداية المسار فقط ويحافظ على باقي المجلدات، أسماء الأغاني، ترتيبها، وتعليقات البلاي ليست. يجب نقل مجلد الأغاني بنفس هيكله إلى المكان الجديد؛ الأداة لا تنقل ملفات الصوت ولا تتحقق من وجودها.

## الخصوصية

المعالجة تتم محليًا داخل المتصفح. لا تُرفع ملفات البلاي ليست أو الأغاني لأي خادم، ولا توجد تحليلات أو مكتبات خارجية. الملفات الأصلية لا تتغير. النسخة المحفوظة على جهازك تعمل بدون إنترنت.

## الصيغ والترميز

- M3U وM3U8؛ UTF-8 وUTF-16 بوجود BOM.
- مع الملفات ذات الترميزات القديمة، تغيير بادئة مسار ASCII يحافظ على بايتات الأسماء الأصلية. المسارات الجديدة غير اللاتينية تتطلب تحويل الملف إلى UTF-8 أولًا.
- الملفات التي لا تحتوي على مسارات مطابقة لا تُضاف إلى ZIP.
- أسماء البلاي ليست المكررة تأخذ لاحقة رقمية داخل ZIP.
